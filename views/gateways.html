New gateway

After you create it, its page guides you through four steps:

  1. Open a port for API calls
  2. Download the credentials file
  3. Start a node with Docker or as a Linux service
  4. Attach it to a catalog to serve its products
The address consumers will call: one node, or the load balancer in front of several. To try it on your own machine, use https://localhost:8443.
